# updates

Signed installers and update manifests for mshin.univ desktop apps.

- Installers are attached to [Releases](../../releases). Each release tag starts with the product name (for example `invoice-v2.0.0`).
- Each product folder holds its current `version.json` (version, SHA-256, download URL).
- Installers are code-signed (publisher: Myung Shin). Check **Properties → Digital Signatures** before running.

This repository contains release files only.
